# Concept Puzzle 기획 반영 내역

반영일: 2026-10-25 / 독립 프로토타입 콘텐츠 버전: 0.1.1

기존 검토용 변경안을 [본 기획서](concept-puzzle-v0.1-plan.ko.md)에 통합했다. **실제 사용자 검증은 아직 수행하지 않았다.** 독립 프로토타입의 계산·화면 검사는 사용자 이해도나 교육 효과를 입증하지 않는다.

## 반영한 내용

1. 기존 CoQuery의 스타일과 학습 화면 구조를 유지하며 개념 퍼즐을 점진적으로 추가하는 원칙을 명시했다.
2. 첫 5분 안내와 9문제 문제은행을 구분하고 자기 설명, 동등한 종료 선택지, 탭 메모리 기록의 범위를 명시했다.
3. 유형별 안내형·독립형·전이형의 데이터·정답·허용 대안·반례·힌트·설명 기준을 [9문제 명세](concept-puzzle-v0.1-puzzle-spec.ko.md)와 [JSON](concept-puzzle-v0.1-puzzles.json)에 정리했다.
4. 검사 실패·응답 대기·취소·수정 요청·제출 철회·회차 종료·신고 철회·항소 취소와 독립 재심 경로를 기획서에 반영했다. 장애를 자동 승인으로 간주하지 않으며 초안 보존과 요약 재검토를 구분한다.
5. [검증 결과](concept-puzzle-v0.1-prototype-verification.ko.md)에 이미 확인한 로컬 동작과 미수행한 사용자·콘텐츠·실기기·운영 검증을 분리했다.
6. 후속 순서를 콘텐츠 독립 검토·사용성 관찰·개선·개인 퍼즐 제품 통합·참여형 폐쇄 파일럿 준비·후속 확대 판단으로 정리했다.

## 작업 경계

PR #22의 문서 전용 브랜치 `docs/`만 변경한다. 실행 HTML·테스트 스크립트·스크린샷은 별도 산출물로 유지하며 제품 코드·API·DB·배포 설정을 변경하지 않는다. 실제 AI·서버 연결·배포·merge는 하지 않는다.
