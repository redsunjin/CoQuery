# PR #31 추가 검증과 리뷰

2026-10-25. 기준: main c31f6c2 → PR #31 feat/journey-onboarding. 배포·앱스토어 제출 없음.

## 판정의 범위

웹 기능과 iOS 빌드/실행을 점검했다. 실제 사용자 연구와 학습 효과 검증은 수행하지 않았다. VoiceOver의 한국어 자막·선택 초점은 확인했지만 실제 음성 품질 및 로터 연속 탐색은 확인 완료가 아니다. 이를 전체 접근성 통과로 표현하지 않는다. 실제 기기 검증 항목은 병합 후 출시 전 확인 목록으로 유지한다.

## 발견한 문제와 수정

1. 공백만 있는 답변의 주장·근거·반례가 HTML required 검사를 통과해 사람 검토 대기에 들어갔다. 신고·항소도 같은 검증 누락이 있었다. trim한 필수 값이 비어 있으면 상태를 바꾸지 않고 오류를 알린다. 부분적으로 쓴 답변은 오류 후에도 유지한다.
2. ‘입력 취소 · 초안 보존’이 요약 단계로 이동하며 기존 요약을 무효화해 실제 상황과 맞지 않는 ‘근거 공개 상태 변경’ 안내를 보여 주었다. 답변 단계에 머무르며 초안 보존 상태를 알리고 기존 요약/확인 상태를 바꾸지 않도록 수정했다.
3. 요약의 출처 링크는 원문 details를 열었지만 접근성 초점은 문서로 돌아갔다. 링크 목적지를 열고 해당 원문으로 초점을 옮기도록 보완했다. URL의 출처 앵커는 유지한다.
4. 새 모의 체험 스크립트는 버전 URL을 사용하고 PWA 캐시는 v12로 갱신했다. 온보딩의 v11 자산 URL과 파일 이름은 유지한다. SQL 계산·퍼즐 정답·기본 시작 버튼·색상·레이아웃은 변경하지 않았다.

## 추가한 회귀 검사

`tests/community_exception_smoke.mjs`는 공백 필수값 거부, 유효한 답변·신고·항소의 trim, 취소 후 초안/단계/기존 요약 보존, 검사 대기 중 발행 금지, 출처 details 열림과 초점 이동을 검증한다. 전체 rc 검사에 포함했다. 웹 UI에서도 공백 입력 차단과 초안 유지·실패/대기/취소를 재현해 확인했다.

오프라인 업데이트는 별도 로컬 서버의 과거 파일을 새 파일로 교체한 테스트다. 파일 수정 시각이 이전 시각으로 복사되어 HTTP 304가 생긴 테스트 준비 문제는 새 수정 시각을 적용해 제거했다. 운영 CDN/캐시 정책, 설치형 PWA의 장기 보관/백그라운드 업데이트, 첫 방문부터 오프라인인 경우를 검증했다는 의미가 아니다.

## 리뷰와 병합 기준

직접 변경점을 검토했다. 사용자 입력은 기존처럼 HTML 이스케이프하며, 자동 발행·계정 제재나 네트워크 요청을 추가하지 않았다. 초안 보존은 모의 체험 탭 메모리 안에만 유지한다. 출처 링크는 현재 문서의 source 앵커로만 이동한다. 제품 데이터 형식·SQL 채점·퍼즐 정답 변경은 없다.

최종 커밋의 원격 baseline/postgresql-smoke/dependency-security 결과, 자동 리뷰 상태와 미해결 지적을 확인한 뒤 병합한다. 자동 리뷰와 작성자 자체 검토를 사람의 독립 사용자 검증으로 표현하지 않는다.

## 남은 실제 기기/사용자 검증

- 실제 iPhone에서 한국어 음성·로터 제목/링크/폼 탐색, 입력 오류·저장 알림 순서, 외부 키보드와 한글 조합 입력.
- 설치형 PWA의 앱 종료/재개·오프라인 버전 전환 및 저장소 제한/퇴거·200% 확대.
- 9퍼즐의 모든 오답·경계·복수 대안 UI 조합과 학생 대상 이해·전이 효과. 이번 자동 명세 검사와 대표 UI 경로 확인을 실제 사람의 학습 성과로 환산하지 않는다.
- SQL 전체 문제의 열 이름 발견성. 이번 첫 문제 안내가 상세 스키마 탐색 개선 전체를 대신하지 않는다.

시뮬레이터의 VoiceOver·자막·키보드 캡처는 점검 전 상태(끔)로 복원했다. 전용 오프라인 서버는 중지했다.

## 최종 UI 추가 확인

최종 수정 자산을 새 로컬 8795 환경에서 열어 출처 A1을 선택했을 때 details.open=true, document.activeElement.id=source-A1임을 확인했다. 9개 퍼즐 모두 대표 정답의 결과 일치와 한글 설명 저장을 UI로 실행했다(C1 A, C2 A/B/C, C3 Q/R, R1 3행, R2 4행, R3 7행, U1 3명/신규2명, U2 2명/신규2명, U3 3명/신규2명). 추가로 C3 초과 기준 R, R3 ID 기준 4행, U3 신규만 규칙의 두 번째 대안 2명/신규2명을 확인해 필수 실험 범위가 완료됨을 확인했다. R1 빈 숫자는 입력란에 초점이 머물고 결과를 생성하지 않았으며, 0행 오답은 실제 3행과 차이를 보여 주었다. 이는 개발자 UI 실행 결과이며 설명의 내용 품질·학습 숙달 평가가 아니다.
