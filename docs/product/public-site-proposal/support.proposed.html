CoQuery 지원 안내

테스터가 문제를 보고하는 방법

TestFlight로 설치한 경우 TestFlight의 피드백 기능을 이용해 주세요. 기기 모델, iOS 버전, CoQuery 버전과 빌드 번호, 문제가 발생한 순서, 기대한 결과와 실제 결과를 함께 남겨 주세요.

스크린샷에는 비밀번호, API 키, 운영 DB 접속 정보나 타인의 개인정보가 포함되지 않도록 확인해 주세요.

현재 안내 범위

  • 샘플 데이터 기반 SQL 연습과 스키마 확인
  • 쿼리 실행, 채점과 힌트, 기기 내 연습 기록
  • 개념 퍼즐 9개: 예상·결과·자기 설명을 기기 안에 기록
  • 참여형 모의 체험: 실제 AI·서버·다른 참여자·계정 제재 없음
  • 현재 TestFlight 0.8.0(7)과 별도 검토 중인 코드의 차이 안내

연습 기록이 보이지 않을 때

같은 기기와 같은 앱에서 확인했는지 살펴봐 주세요. 기기 내 데이터는 앱 삭제나 저장소 초기화로 사라질 수 있으므로, 재설치 전에 재현 정보를 남겨 주세요.

검토 중인 조건 탐구의 저장 범위

조건 탐구는 브라우저/기기 안의 기록을 사용하며 서버로 보내거나 기기 간 동기화하지 않습니다. 창작은 편집 초안과 마지막 저장본 한 개를 구분합니다. 저장소를 쓸 수 없으면 현재 탭에만 남습니다. 이 기능은 아직 배포되지 않았습니다. 실제 설치 버전과 빌드 번호를 확인해 주세요.
