## 이번 수직 흐름과 성공 기준

가설: SQL 입력 부담 없이 예상의 차이와 반례를 확인하면 조건 논리를 자신의 말로 설명하고 다른 상황에서 적용하기 쉬워진다. 아직 실제 사람에게 확인하지 않았다.

1. 홈은 개념 중심 제목과 ‘조건 탐구 시작 / 이어가기’를 주요 행동으로 제공한다. SQL 시작/문제 선택·9퍼즐·고급 도구는 유지한다. ‘전체 진행률’은 ‘SQL 연습 진행률’로 정정한다.
2. 이해: 그리고=두 조건 모두, 또는=하나 이상(둘 다 포함). 안내형 그리고와 독립형 또는를 각각 예상·실험한다. 오답을 실패 점수로 기록하지 않는다.
3. 반례: ‘빨강이면 모두 그리고에 남는다’를 깨는 B를 직접 고른다. A/C/D에는 다른 복구 설명을 준다.
4. 자기 설명: B의 제외/포함과 A의 포함을 자기 말로 쓴다. 입력 보존과 내용 평가는 별개다.
5. 전이형: 이야기책/짧은 책이라는 새로운 맥락에 적용하고 두 규칙을 비교한다. 이것은 가까운 전이 과제이며 실제 전이 능력 입증이 아니다.
6. 창작: 두 조건 이름·4개 항목·참/거짓·연산을 바꾸고 예상·실행·의도/반례를 기록한다. 현재 편집본과 마지막 저장본을 분리하며 재실행·수정 가능. 저장 1개, 공유/계정/동기화 없음. 빈 결과와 모두 포함도 허용한다.
7. 선택 SQL: 같은 유한 데이터의 CTE 표현을 보여 준다. UI 계산을 SQL 엔진 실행이라고 주장하지 않는다. 기존 SQL 학습으로 전환한 뒤 홈에서 탐구로 복귀한다.
8. 목적 중심 도움: 각 단계의 생각할 질문을 제공한다. 이 로컬 도움을 실제 AI Assist라고 부르지 않는다. 기존 고급 Assist 설정·정책은 변경하지 않는다.

기능 수용 기준: SQL 없이 기본 흐름 진입, 예상/실제 근거 확인, 잘못된 반례 복구, 설명 보존, 새 맥락 실험, 창작 변경 후 결과 무효화, 마지막 저장본 복원·수정·재실행, 재방문 단계 보존, SQL 기록 오염 없음, PWA/iOS 자산 누락 없음. 실제 사용자·출시 기준은 별도 검증 프로토콜을 따른다.

## 제품 범위의 한계

관계/규칙 주제의 연결된 탐구·창작 여정은 아직 없다. 새로운 조건 여정도 자유 형식 모델링 도구나 논리 교육 완제품이 아니다. 기존 9문제·SQL 24문제·참여형 모의 체험은 유지되며 이번의 핵심 성과는 한 주제의 경험 연결이다. 설치·실기기·독립 교육 검토·실제 사용자 관문 전까지 내부 베타 판정을 유지한다. TestFlight 추가 업로드/배정, 공개 웹 배포, App Store 제출/출시는 하지 않는다.
