# 실제 초보자 검증과 출시 관문

2026-10-25. **모집·연락·관찰·사람의 설명 평가는 아직 실시하지 않았다.** 아래는 실행 가능한 연구 계획이며 측정 결과가 아니다. 승인 없이 대외 메시지를 보내지 않는다.

## 검증 단계와 관찰지

첫 라운드는 SQL을 모르는 성인 초보자 6명, 다음 수정 후 새로운 성인 초보자 6명으로 제안한다. 학생/미성년자 참여는 이 성인 연구와 분리하며 보호·동의 절차와 기관 협의를 먼저 정한다. 독립 교육자 2인이 문장·정답·반례·전이 과제의 적절성을 사전 검토한다. 에이전트 자체 검토를 독립 교육자 검토로 대체하지 않는다.

진행자는 방법을 시연하지 않고 “조건이 어떻게 다른지 알아보고 자신의 퍼즐을 만들어 보세요”만 전달한다. 말하기 부담이 있는 참가자는 글·선택·가리키기를 사용할 수 있다. 수행 전 개인정보 없는 시험 ID, 콘텐츠 버전, 동의 여부, 사용 기기/접근성 방식만 기록한다. 영상과 자유 설명 원문 보관은 별도 선택 동의를 받는다. 제품에 분석 전송을 자동 추가하지 않는다.

| 과제 | 관찰 내용 | 질문 / 판단 근거 |
|---|---|---|
| 첫 화면에서 시작 | 첫 행동·시간·도움 요청·SQL 선택 이유 | “어떤 일을 할 수 있다고 생각하나요?” 30초 내 개념 진입 여부 |
| 그리고 예상→실험 | 처음 예상·수정·근거 표 활용·막힘 위치 | “왜 B가 빠졌나요?” 정답 클릭과 이유를 구분 |
| 독립형 또는 | A도 포함하는지·안내 없이 예상하는지 | “둘 다 맞는 항목은 어떻게 되나요?” 배타적 OR 착오 기록 |
| 반례 | 주장을 깨는 예와 그냥 제외된 예 구분 | “이 예가 주장을 깨는 이유는?” B만 골라도 이유 없으면 설명 충족 아님 |
| 자기 설명 | 두 연산·둘 다 포함·반례의 연결 | 두 검토자가 익명 설명을 별도 평가하고 불일치 원인 기록 |
| 새 맥락 | 이야기책/짧은 책 적용·규칙 변경 | “짧은 이야기책은 어디에 남나요?” 암기된 카드 이름 없이 설명 |
| 먼 전이(제품 밖) | 표면과 배치를 바꾼 새 과제 | 버스 ‘저상 또는 야간’ 4개 + 새 사례 추가; 안내 없이 포함/제외 이유와 반례 1개. 제품 과제와 다른 순서·명칭 사용 |
| 창작 | 의도·조건명·데이터·실제 결과가 일치하는지 | 한 조건만 맞는 예와 둘 다 맞는 예를 스스로 만들고 결과 예측 |
| 저장·복귀·수정 | SQL 왕복·새로고침·저장본 복원 | 현재 초안과 저장본 구분, 기록 유실/혼동 여부 |
| 마무리/이탈 | 실제 중단 화면·말·도움 유무 | 종료는 자유. 2분 이상 무행동을 원인 질문 계기로만 쓰며 실패/무능으로 추정하지 않음 |

관찰 표 양식: 시험ID / 버전 / 과제 / 첫 예상 / 실제 행동 / 첫 막힘 화면 / 진행자 개입 문구·시각 / 수정 후 설명 / 전이 근거 / 중단 여부·본인 사유 / 저장 이해 / 결함ID. 사람의 원문은 기본 저장소·PR에 올리지 않는다. 보고에는 비식별 사례와 작은 표본의 실제 분모를 함께 쓴다.

설명 루브릭(학습 가설 점검용): 0=설명 없음 또는 두 규칙 혼동, 1=하나를 설명하지만 둘 다 맞는 예나 반례에서 모순, 2=두 규칙과 둘 다 포함을 설명하며 구체적 반례 제시. 정답률·문장 길이·체류 시간으로 점수를 대신하지 않는다. 7일 후 명칭/맥락이 다른 조건 과제로 지연 전이를 따로 측정한다. 소규모 사용성 관찰에서 교육 효과의 인과성을 주장하지 않는다.

## 확대·출시 판단

아래 수치는 제안 목표다. 미달 항목은 실제 막힌 원인을 고친 뒤 새 참가자로 재검증한다. 소표본 비율을 전체 인구 성공률로 해석하지 않는다.

- 콘텐츠: 별도 2인 독립 검토, 정답·반례·표현의 중대 모순 0개. 불일치 해결 기록 필요.
- 두 번째 성인 라운드: 6명 중 5명 이상이 도움 없이 30초 내 개념 진입. 안내형/독립형/전이형의 각 중단 지점과 지원 요청을 전부 기록.
- 이해: 6명 중 5명 이상이 두 규칙·둘 다 포함·반례를 설명 루브릭 2로 설명. 단순 완료를 대체 지표로 쓰지 않음.
- 전이·창작: 6명 중 4명 이상이 제품 밖 새 과제의 이유와 반례를 제시하고, 만든 규칙의 변경 결과를 설명. 7일 후 과제는 별도 결과로 보고. 미실시는 미실시로 표시.
- 기록: 설명·창작·SQL 진도 손실 또는 다른 기록 삭제 0건. 저장 제한 환경은 임시 기록임을 이해해야 함.
- 접근성·환경: 실제 iPhone의 한글 입력·음성·로터 연속 탐색·외부 키보드, Safari, 200% 확대, 설치형 PWA의 업그레이드/오프라인/복귀 확인. 시뮬레이터/화면 폭 검사로 대체하지 않음.
- 안내 일치: 설치 빌드·소개·지원·스토어 문구와 스크린샷의 기능/버전 일치. 배포 승인과 기술 병합은 별개.
- 운영 범위: 참여형은 명확한 별도 모의 체험. 실제 커뮤니티 출시는 인증·권한·삭제·독립 재심·운영 인력과 별도 검증/승인 필요.

현재 모든 사람 기반 관문은 미통과(미실시). 제품 전환 완료·학습 효과·정식 출시 적합성을 선언하지 않는다. 자동 회귀, 브라우저 개발자 실행, iOS 자산/시뮬레이터, 합성 페르소나 점검은 각각 기능 근거로만 별도 기록한다. 100개 합성 페르소나/900개 고정 실행은 이 연구의 표본이나 성공률에 합산하지 않는다.
