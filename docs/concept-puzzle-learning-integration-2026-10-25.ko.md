# CoQuery 학습 화면에 개념 퍼즐 통합

기록일: 2026-10-25. [검토한 9문제 명세](concept-puzzle-v0.1-puzzle-spec.ko.md)를 기존 학습 홈에 선택 경로로 추가한다. 실제 사용자 검증과 별도 교육자 2인의 검토는 아직 수행하지 않았다.

## 사용자 경로

기존 SQL 홈의 제목·첫 문제·문제 선택·고급 기능·24문제 진행 기록은 유지한다. 같은 스타일의 `개념 퍼즐 9개` 보조 버튼을 추가한다. 영어 홈에서는 한국어 콘텐츠임을 표시한다. 개념 화면에서 `SQL 학습 홈`으로 돌아오면 기존 SQL 경로를 계속 사용할 수 있다.

개념 퍼즐은 조건 탐정 C1~C3, 관계 연결 R1~R3, 규칙 바꾸기 U1~U3로 구성된다. 고정 가상 데이터에 조건·연결·규칙을 적용해 결과를 계산하며 SQL 명령·DB·AI 제공자를 호출하지 않는다. 두 기준 비교와 규칙 대안 수를 통해 필수 실험 범위를 표시하지만 이해도·숙달 점수로 쓰지 않는다. 자기 설명은 자동 채점하지 않는다.

## 기록과 참여형 체험 분리

개념 기록과 자기 설명은 `coquery.concept-puzzles.v1` 브라우저/기기 로컬 저장소에 버전별로 저장한다. 기존 SQL 기록 키를 사용하지 않으며 `개념 기록 지우기`는 개념 기록만 지운다. 개념 화면에서 수집·전송·동기화하지 않는다. 저장 실패 시 현재 탭의 기록으로 동작하며 화면에 알린다. 공용 기기에서는 자기 설명도 지워야 한다.

참여형 기능은 `community-demo.html`의 별도 모의 체험으로 이동한다. 실제 AI·서버·다른 참여자 연결, 계정·권한·실제 감사 체계를 구현하지 않는다. 질문 검사·발행 대기·답변·요약·신고·독립 항소와 실패·대기·취소는 고정 시나리오다. 이 페이지는 SQL 런타임을 로드하지 않고 개념/SQL 기록을 읽지 않으며 입력은 탭 종료·새로고침 때 사라진다.

## 웹 PWA와 iOS 자산

새 카탈로그·화면·스타일과 모의 체험 자산을 PWA `v7` 캐시 및 iOS 명시적 자산 목록에 포함한다. 카탈로그는 코드에 내장되어 실행 시 JSON/API 요청이 필요 없다. Cloudflare 묶음에도 같은 정적 자산이 포함된다. 이번 작업에서는 배포하지 않는다.

온라인에서 자산을 캐시한 PWA는 오프라인 재실행 후에도 개념 퍼즐을 계산하고 모의 체험을 열 수 있다. 기존 SQL 서버 요청은 연결이 필요하다. 초기 요청 실패가 처리되지 않은 예외가 되지 않도록 PWA 명령 런타임에서 빈 결과 대신 `ok:false`와 연결 필요 메시지를 반환한다. 세션 목록 요청 실패는 목록 없음으로 처리한다. SQL 결과·채점 성공을 만들어내지 않는다.

## 확인한 검사

- 순수 카탈로그/평가 검사: 문서 데이터와 런타임 9문제의 일치, C3 경계값, R3 동명이인 7/4행, 규칙 조합 24개, 필수 실험 범위 판정.
- 원래 SQL 핵심 테스트 121개 및 릴리스 검사, SQL 방언·학습 경로·PWA 정적 계약 검사.
- 로컬 Chromium: 기존 SQL 홈, 9문제 결과·두 기준·대안 비교, 설명 보존·초기화, SQL 첫 문제 재진입, 개념 조작 중 명령 API 호출 없음.
- 별도 모의 체험에서 질문→발행 대기→요약→신고·항소 완료. 모의 입력에서 POST 요청 없음.
- 온라인 캐시 후 네트워크를 끄고 재실행하여 개념 정답 확인·별도 모의 체험 진입. 페이지 실행 오류 없음.
- 1440px/390px 화면을 확인했다. 실제 스크린리더·Safari·물리적 iPhone/iPad 검증은 미수행이다.
- iOS 자산 묶음 및 기존 24문제 SQLite 실행·채점 패키지 검사를 통과했다. 실제 기기 또는 App Store 업로드 증거는 아니다.

사용자 연구, 실제 커뮤니티 운영, AI 품질·운영 안전성 검증은 이 동작 검사로 대체하지 않는다. 배포와 앱스토어 제출은 별도 작업이다.
