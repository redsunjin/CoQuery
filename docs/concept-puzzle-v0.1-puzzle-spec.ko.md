# Concept Puzzle 9문제 콘텐츠 명세

콘텐츠 버전: 0.1.1 / 기록일: 2026-10-25

**실제 사용자 검증은 아직 수행하지 않았다.** 이 명세는 독립 프로토타입에 구현한 고정 가상 데이터와 결과 기준이다. 교육자 등 2인의 독립 콘텐츠 검토와 초보자·학생 검증은 미완료다.

## 데이터와 결과 해석

입력 데이터와 허용 해는 [문서용 JSON](concept-puzzle-v0.1-puzzles.json)에 둔다. 실행 파일이나 제품 문제은행 변경이 아니다. `미시도 → 실험 확인 → 설명 기록` 상태를 구분하며 결과 확인·예측 일치·설명 기록을 숙달 점수로 쓰지 않는다. 자유 설명은 자동 채점하지 않고 아래 기준으로 사람이 검토한다.

### 공통 가상 데이터

- C1/C2 카드: A=빨강·원, B=빨강·네모, C=파랑·원, D=파랑·네모, E=노랑·세모, F=초록·별.
- C3 점수: P=9, Q=10, R=11.
- R1/R2 회원: m1=솔, m2=별, m3=달. 대여: l1=m1·책 A, l2=m1·책 B, l3=m2·책 C.
- R3 추가 데이터: m4=솔, l4=m4·책 D. 이름으로 연결할 때 대여 이름은 원본 회원 ID에서 가져온다.
- U1/U2 신청자: 가=3점·기존, 나=3점·신규, 다=2점·신규, 라=1점·신규. U3에는 마=4점·신규를 추가한다.

## 문제별 과제와 검토 기준

### C1 안내형 두 조건을 모두 만족하기

빨강 그리고 원인 카드를 모두 예상해 보세요.

- **결과·해설**: A만 두 조건을 모두 만족합니다. B는 원이 아니고 C는 빨강이 아닙니다.
- **힌트**: A와 B는 모두 빨강이지만 모양은 다릅니다.
- **반례**: 빨강이기만 한 B를 포함하면 AND 조건에 맞지 않습니다.
- **설명 검토 기준**: 두 조건을 모두 만족해야 함을 설명하고, B 또는 C가 제외되는 이유를 말한다.

### C2 독립형 하나 이상이면 남기기

빨강 또는 원인 카드를 모두 예상해 보세요. 또는은 하나 이상을 뜻합니다.

- **결과·해설**: A·B·C가 남습니다. B는 빨강, C는 원이며 A는 둘 다 만족합니다.
- **힌트**: 두 조건을 모두 만족하는 A도 포함됩니다.
- **반례**: 두 조건을 모두 만족하는 A를 빼는 해석은 이 퍼즐의 OR가 아닙니다.
- **설명 검토 기준**: 포함적 OR를 설명하고 A가 제외되지 않는 이유를 말한다.

### C3 전이형 10 이상과 10 초과

가상 점수 P=9, Q=10, R=11입니다. 기준을 바꿔 두 경우를 모두 예측해 보세요.

- **결과·해설**: 10 이상은 Q·R, 10 초과는 R만 포함합니다. 10은 이상에만 포함됩니다.
- **힌트**: 경계값과 같은 Q=10을 먼저 확인해 보세요.
- **반례**: 10 초과에 Q=10을 포함하면 경계 조건에 맞지 않습니다.
- **설명 검토 기준**: 값 10의 포함 여부를 설명하고 두 규칙의 결과 차이를 말한다.

### R1 안내형 한 사람에게 여러 기록

회원 ID로 연결하고 대여 기록이 있는 회원만 남깁니다. 결과 행 수를 예상해 보세요.

- **결과·해설**: 솔–책 A, 솔–책 B, 별–책 C의 3행입니다. 달은 대여가 없습니다.
- **힌트**: 솔의 대여 기록은 책 A와 책 B 두 개입니다.
- **반례**: 회원 수 3명과 결과 3행은 우연히 같습니다. 회원 수로 항상 행 수를 예측할 수 없습니다.
- **설명 검토 기준**: 솔이 두 행이 되는 이유와 달이 빠지는 이유를 설명한다.

### R2 독립형 기록이 없어도 남기기

회원 ID로 연결하되 모든 회원을 남깁니다. 결과 행 수를 예상해 보세요.

- **결과·해설**: 기존 3행에 달–대여 없음이 추가되어 4행입니다.
- **힌트**: 달은 없어지는 대신 대여 없음이라는 행으로 남습니다.
- **반례**: 대여가 없다고 달을 제외하면 모든 회원을 남긴다는 목표에 어긋납니다.
- **설명 검토 기준**: 연결되지 않은 회원을 남기는 조건과 대여 없음의 의미를 설명한다.

### R3 전이형 이름이 같으면 같은 사람일까요?

솔이라는 이름의 회원 m4와 책 D 대여가 추가되었습니다. 이름 연결과 ID 연결의 행 수를 모두 예측해 보세요.

- **결과·해설**: 이름 기준은 솔 2명 × 솔의 대여 3개 + 별 1행 = 7행입니다. ID 기준은 각 대여가 실제 회원 1명에 연결되어 4행입니다.
- **힌트**: 이름 솔인 회원 2명과 이름 솔로 표시된 대여 3개가 이름 기준으로 조합됩니다.
- **반례**: m4가 책 A를 빌렸다고 이름만으로 연결하면 원본 회원 ID m1과 어긋납니다.
- **설명 검토 기준**: 동명이인으로 생긴 잘못된 조합을 짚고 ID 연결에서 4행이 되는 이유를 말한다.

### U1 안내형 신규 참여 기회를 늘리기

최소 2명, 그중 신규 2명 이상을 고르는 규칙을 찾아보세요. 정원 제한은 없습니다.

- **결과·해설**: 여러 해가 가능합니다. 1점 이상으로 모두 선택하는 규칙도 목표를 충족합니다. 선택 인원과 제외되는 사람을 비교해 보세요.
- **힌트**: 2점 이상 또는 2점 이상이며 신규만을 비교해 보세요.
- **반례**: 3점 이상은 신규가 나 1명뿐이므로 목표를 충족하지 못합니다.
- **설명 검토 기준**: 목표 충족을 확인하고 두 대안의 선택 인원·제외되는 사람·부담 차이를 설명한다.
- **허용 해 전체**: 점수 1 이상 / 점수 1 이상이며 신규만 / 점수 2 이상 / 점수 2 이상이며 신규만. 점수 기준 1·2·3·4와 신규 조건 켬/끔의 8개 조합 안에서의 전체 해다. 자유 규칙 전체의 완전성은 주장하지 않는다.

### U2 독립형 정원이 두 명이라면

최소 2명, 신규 2명 이상을 고르되 정원은 2명입니다.

- **결과·해설**: 2점 이상이며 신규만 선택하면 나·다 2명으로 목표와 정원을 충족합니다.
- **힌트**: 모두 선택하면 정원을 넘습니다. 신규 조건도 바꿔 보세요.
- **반례**: 1점 이상이며 신규만은 나·다·라 3명으로 정원을 초과합니다.
- **설명 검토 기준**: 신규 2명과 정원 2명을 각각 확인하고 전원 선택이 실패하는 이유를 말한다.
- **허용 해 전체**: 점수 2 이상이며 신규만. 점수 기준 1·2·3·4와 신규 조건 켬/끔의 8개 조합 안에서의 전체 해다. 자유 규칙 전체의 완전성은 주장하지 않는다.

### U3 전이형 데이터가 바뀌면 해도 바뀔까요?

신규 마(4점)가 추가되었습니다. 최소 2명, 신규 2명 이상, 정원 3명을 만족하는 대안 두 개를 찾아보세요.

- **결과·해설**: 3점 이상은 가·나·마, 2점 이상이며 신규만은 나·다·마입니다. 둘 다 목표를 충족하지만 제외되는 사람이 다릅니다.
- **힌트**: 3점 이상과 2점 이상이며 신규만의 결과를 비교해 보세요.
- **반례**: 모든 신청자를 선택하면 5명으로 정원 3명을 넘습니다.
- **설명 검토 기준**: 서로 다른 두 해와 제외되는 사람을 비교하고 목표 충족과 공정성 판단을 구분한다.
- **허용 해 전체**: 점수 2 이상이며 신규만 / 점수 3 이상 / 점수 3 이상이며 신규만. 점수 기준 1·2·3·4와 신규 조건 켬/끔의 8개 조합 안에서의 전체 해다. 자유 규칙 전체의 완전성은 주장하지 않는다.

## 발행 전 확인할 항목

- [ ] 별도 검토자 2인이 정답·반례·문장·목표 적합성을 독립 검토한다.
- [ ] 초보자가 새 상황에서도 이유와 반례를 설명하는지 확인한다.
- [ ] 실제 모바일 브라우저·스크린리더·키보드로 조작을 확인한다.
- [ ] 결과 일치를 교육 효과·공정성·안전성으로 확대 해석하지 않는다.

계산 및 화면 검사 범위는 [프로토타입 검증 결과](concept-puzzle-v0.1-prototype-verification.ko.md)를 따른다.
