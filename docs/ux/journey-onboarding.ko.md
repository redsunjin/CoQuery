# CoQuery 기능·사용자 여정·테스트·온보딩

2026-10-25 · 기준 main c31f6c2 · 별도 feat/journey-onboarding 작업. 배포·앱스토어 제출 없음.

## 읽는 방법
현재 제공 기능은 코드/로컬 화면에서 확인한 사실이다. ‘기대 이익’은 제품 가설이며 실제 사용자·학생의 학습 효과를 입증하지 않는다. 이번 테스트는 개발자 관점의 기능 점검이다. 기존 대한민국 합성 페르소나 100건/900개 고정 실행은 대표 표본이나 사람의 응답이 아니므로 성공률·효능 근거로 재사용하지 않았다. 설계 페르소나는 SQL 초보자, 개념부터 시작하는 학습자, 검토 과정을 익히는 진행자이며 실제 인구집단을 대변하지 않는다.

## 기능 지도
- Learn: SQL 24문제·학습 경로·힌트·시도 이력. 질문 읽기→SQL→결과→다음 학습.
- Practice: 조건 탐정 C1/C2/C3, 관계 연결 R1/R2/R3, 규칙 바꾸기 U1/U2/U3. 예상→실험→반례→자기 설명. SQL과 별도 로컬 기록.
- Apply: 고급 작업 공간에서 데이터/질의 작업으로 확장. Query Graph 및 Result Intelligence의 표·흐름·해설은 결과 이해 보조이며 인과관계나 이해도 검증이 아니다.
- Assist: 별도 설정이 필요한 선택 기능. 이번에는 실제 AI 요청·외부 DB를 실행하지 않았다.
- 참여형 모의 체험: 질문→고정 AI 검사 예시→정제 선택→사람 발행 검토→구조화 답변→요약/출처→신고/항소. 실제 AI·다른 사람·제재·서버 저장 없음.
- 웹/PWA/iOS는 셸 자산을 재사용한다. 자산 포함 검사 통과와 실제 기기 사용성 검증은 다르다.

## 이번에 직접 수행한 점검
새 로컬 서버 8792의 최신 작업 화면을 사용했다. 기존 8767 프로토타입 화면은 현재 제품 검증 근거로 쓰지 않았다. SQL 빈 입력→없는 열 오류→SELECT id, name, region FROM customers ORDER BY id; 실행→정답 4행·진행 1/24 확인. C1 결과 불일치와 반례 설명, 한글 자기 설명 저장·평가 전 상태 확인. 모의 검사 실패→취소→초안 보존→정상 검사 제안 화면 확인. 영어 전환과 Enter로 안내 펼치기도 확인했다. 새 사용자 localhost 환경에서 세 안내 경로 전환·읽음 표시·닫기 초점·새로고침 지속 확인. 읽음만으로 SQL 진행률은 0/24에서 변하지 않았다.

자동 검사: npm run rc:verify 통과(핵심 CLI/Command API·SQL 방언·셸·9퍼즐/경계/조인/24대안·iOS 자산·기타 계약), npm run ios:shell:test 통과. 자동 계약 검사를 9문제 전부를 사람이 직접 풀었다는 뜻으로 해석하면 안 된다. 추가 수동 점검에서 질문 승인→주장/근거/반례 답변→답변 사람 승인→요약의 사실/의견 분리와 A1/A2/A3 출처 링크 표시→요약 확인→신고→M1 임시 비공개→항소→M2 원결정 변경→공개 복원·요약 재확인 요구까지 확인했다. 출처 링크의 실제 이동과 모든 예외 조합은 추가 검증 대상이다.

## 발견과 대응
1. J01 시작 경로의 설명 부족: 기존 4개 시작 버튼과 스타일을 유지하고 선택해서 펼치는 목적별 안내를 추가했다. 강제 팝업·자동 학습 완료·새 AI 연결은 없다.
2. J02 스키마 요약은 열 목록 대신 테이블/열 개수만 드러난다. 처음 쓰는 사람이 열 이름을 추론하기 어렵다. 이번 안내에 첫 문제의 정확한 열 이름을 제공했지만 전체 문제의 구조 탐색 개선은 남는다. 표/스키마 상세를 보강한 후 신규 사용자 과제로 재검증할 것.
3. 기존 127.0.0.1 사용 세션에서 새 HTML과 이전 캐시 자산이 섞여 안내 본문이 비는 상태를 관찰했다. 신규 localhost 환경은 정상이다. 서비스 워커 v11과 안내 자산 URL 버전을 함께 올려 수정했다. 같은 기존 세션을 다시 열어 안내 본문·경로 선택·SQL 이어가기가 정상인 것을 확인했다. 오프라인 업데이트 전환은 별도 검증이 필요하다.
4. VoiceOver 실제 낭독·로터, 새 안내의 실제 iPhone 사용, 모바일 크기·오프라인 업데이트·저장소 차단은 이번 실행 미완료다. 기존 검증 결과를 이번 통과로 합산하지 않는다.

## 온보딩 설계
홈에서 ‘처음이라면: 사용법과 세 가지 시작 방법’을 펼친다. 개념/SQL/함께 검토 중 하나를 고르면 목적→4단계 사용법→기록과 모의 기능의 한계→해당 경로 시작을 제공한다. 항상 다시 열 수 있다. 읽음 표시는 로컬 coquery.guide.v1 하나이며 계정·분석 전송·학습 점수와 무관하다. 한국어/영어 안내를 지원하되 개념/참여형 콘텐츠가 한국어라는 점을 영어 안내에 명시했다.

## 다음 실행 계획과 승인 기준
- P0: 기존 캐시 설치→버전 교체→온라인/오프라인 재진입에서 본문·행동이 같은 버전인지 확인. 미충족 시 출시 보류.
- P1: J10 기본 경로를 바탕으로 남은 실패/대기/취소·중복 입력·빈 근거·신고/항소 검토 분리를 재실행. 대기나 AI 실패가 자동 게시/제재로 이어지면 불합격.
- P1: SQL 24문제의 스키마 발견성·오답 복구, 9퍼즐을 UI에서 각각 정답/오답/경계/반례/설명 저장으로 검증. 자동 명세 검사와 별개 증거를 남긴다.
- P1: 390px 모바일·키보드만 사용·200% 확대·한글 조합 입력·저장소 차단·PWA 오프라인·iOS 실제 화면. 잘림·초점 유실·진도 오염은 불합격. VoiceOver 음성/로터는 실제 기기에서 별도 확인.
- P2 실제 사용자: 성인 초보 5~8명에게 안내 없이 목적 찾기→안내 사용→첫 과제→다음 날 설명을 부탁한다. 학생 대상은 별도 모집/보호 절차로 진행한다. 후보 목표는 5분 내 첫 과제 완료 80% 이상, 모의 기능/로컬 저장을 정확히 설명 80% 이상, 도움 요청·오류 회복 시간을 기록하는 것이다. 이는 앞으로 검증할 목표이며 측정 결과가 아니다. 소표본을 전체 사용자 비율로 일반화하지 않는다.
- 효과 검증: 개입 전후 새로운 문제에서 조건/관계/규칙 설명과 반례 생성의 변화를 관찰하고, 정답 암기·안내 따라하기와 구분한다. 합성 데이터나 자동 체크로 학습 효과를 대신 판단하지 않는다.

현재 판정: 핵심 회귀 검사·모의 검토 기본 전체 경로 통과, 온보딩 신규/기존 캐시 환경 동작 확인, 전체 여정 QA는 미완료. 실제 사용자 검증·배포·앱스토어 제출은 수행하지 않았다.

## PR #31 추가 점검

모바일·오프라인 업데이트·여정 예외 경로의 최신 결과는 [추가 검증 보고서](../qa/pr31-journey-verification-2026-10-25.ko.md)를 따른다. 공백 답변/신고/항소 검증, 입력 취소의 단계/초안 보존, 출처 링크 초점을 보완했다. 웹 오프라인 업데이트와 iOS 빌드/표시는 확인했으며 실제 VoiceOver 음성·로터 및 사용자 학습 효과는 여전히 미확인이다.
