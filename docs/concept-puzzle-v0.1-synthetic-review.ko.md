# Concept Puzzle 한국 합성 페르소나 시뮬레이션과 콘텐츠 검토

기록일: 2026-10-25. 대상: 독립 HTML 프로토타입과 PR #22의 9문제 명세. **실제 사용자 검증은 아직 수행하지 않았다.**

## 결과와 해석

9문제의 정답 집합, 관계 연결 결과, 규칙 조합 24개의 허용 해는 별도의 데이터 계산과 일치했다. 기존 한국 합성 페르소나 로컬 샘플 100개에 고정 과제·오류·재시도 정책을 연결해 Chromium에서 900개 시나리오를 재생했고, 최종 예상 결과·설명 기록 상태의 동작 검사는 900개 모두 통과했다.

이는 응답을 스크립트로 지정한 회귀 검사다. 100명의 사람이 9문제를 이해했다는 의미도, 합성 응답자가 실제로 추론했다는 의미도 아니다. 성공률·만족도·학습 속도·교육 효과를 추정하지 않는다. 자유 설명 입력도 루브릭 문구를 시험값으로 사용했으며 설명 품질은 평가하지 않았다.

## 사용 자료와 범위

- 출처: NVIDIA, [Nemotron-Personas-Korea](https://huggingface.co/datasets/nvidia/Nemotron-Personas-Korea), CC BY 4.0. 원본 자료는 대한민국 성인 19세 이상을 포함한 합성 데이터다.
- 기존 로컬 파일: `nemotron-100-sample.jsonl`, 100행, 연령 범위 20~94세. SHA-256: `a11086681af0356d60f8b9ed78dfad08ac9800e50977c504dd942e5fd616682e`.
- 이전 다운로드 기록과 스키마를 확인한 로컬 head 샘플이다. 원본 데이터셋 revision이 기록되어 있지 않아 100행 전체를 최신 원격 데이터와 재대조하지 않았다. 한국 인구를 대표하는 표본이 아니다.
- 별도로 찾은 `nemotron-korea-expanded-sample.jsonl` 20행은 원본 추출본이 아닌 필드 구조 기반 테스트 샘플이므로 이번 100행 시뮬레이션에서 제외했다.
- 원본 페르소나 문장·이름·상세 주소·원본 UUID는 제품이나 공개 저장소에 넣지 않는다. 결과에는 KR-001 같은 시험 식별자와 집계만 남긴다.

## 방법

페르소나의 서술 필드는 생활·가족, 학습·기술, 생활·업무라는 넓은 과제 맥락 태그에만 사용했다. 과제의 실제 데이터와 정답은 공통으로 유지했다. 연령·성별·직업으로 문해력·인지 능력·오류 확률을 추정하지 않았다.

상호작용 조건은 인구통계와 별개로 순번에 따라 배정했다. 390px 모바일, 1440px 데스크톱 키보드, 720 CSS px 재배치 조건을 대표 브라우저 조작으로 확인했다. 마지막 조건은 1440px 화면의 200% 확대에 대응하는 재배치 근사이며 브라우저의 실제 확대 기능을 검증한 것은 아니다. 고정 오류 정책은 OR의 배타적 해석, 경계값 포함 착오, 회원 수와 결과 행 수 혼동, 정원 초과를 시험한다. 오류를 실제 페르소나의 행동이라고 주장하지 않는다.

각 페르소나·문제 실행의 상태를 초기화했다. C3와 R3는 두 기준을 비교하고, U3는 대안 비교 정책에서 서로 다른 규칙을 확인한다. 900개 검사는 브라우저 상태·화면을 프로그램으로 진행한 것이며 900회 전 과정을 실제 마우스·키보드로 조작한 사용성 연구가 아니다. 대표 조건에서는 실제 컨트롤 클릭·키 입력과 화면 확인을 병행했다.

## 정답 반례 설명 기준 검토

| 문제 | 계산과 반례 검토 | 설명에서 확인할 것 |
|---|---|---|
| C1 | 빨강 AND 원은 A. 빨강만인 B는 반례다 | 두 조건 모두 필요함을 설명한다 |
| C2 | 포함적 OR는 A·B·C. A를 제외하는 해석은 틀리다 | 하나 이상이며 둘 다도 포함됨을 설명한다 |
| C3 | 10 이상은 Q·R, 10 초과는 R | 10의 포함 여부를 다른 예에도 적용한다 |
| R1 | ID 연결 3행. 솔은 대여 2개로 2행이다 | 회원 수와 결과 행 수를 구분한다. 우연히 3이라는 숫자만 맞춘 답은 이해 증거가 아니다 |
| R2 | 모든 회원을 남기면 달–대여 없음이 더해져 4행 | 기록 없음과 회원 자체의 누락을 구분한다 |
| R3 | 이름은 7행 중 잘못 연결된 3행, ID는 4행 | 동명이인으로 생기는 잘못된 조합을 말한다 |
| U1 | 4개 허용 해. 정원 제한이 없어 전원 선택도 해다 | 선택 인원·제외되는 사람·부담의 차이를 비교한다 |
| U2 | 제한된 8조합 중 2점 이상·신규만이 해다 | 목표와 정원을 각각 확인한다 |
| U3 | 제한된 8조합 중 3개 해가 있다 | 서로 다른 두 대안과 제외되는 사람을 비교하고 공정성 의견과 계산 결과를 구분한다 |

현재 에이전트의 검토이며 별도 교육자 2인의 독립 검토는 아니다. 자기 설명은 자동 채점하지 않는다. 데이터의 성인 범위로 학생·미성년자의 UX를 검증했다고 말할 수 없다.

## UX 발견과 조치

1. **설명 기록과 과제 범위가 혼동될 여지**: U3에서 대안 하나만 확인해도 설명을 기록할 수 있었고, C3/R3도 한 기준만 확인한 기록을 남길 수 있었다. 설명 저장을 막지는 않되 ‘추가 실험 필요’와 ‘필수 실험 확인’을 별도 표시하도록 독립 프로토타입을 보완했다. 둘 다 숙달 판정은 아니다.
2. **유형별 추가 안내 필요**: R1은 우연히 회원 수와 결과 행 수가 같고 U1은 전원 선택이 해다. 숫자 정답이나 목표 충족만으로 설명 점수를 부여하지 않고 기존 반례·루브릭을 유지한다. 이 부분은 실제 관찰에서 우선 확인한다.
3. **기존 스타일 유지**: 어두운 배경, CQ 마크, 보라색 강조, 파란 주요 버튼과 기존 문제 선택 구성을 유지했다. 새로운 화면 체계나 제품 코드를 도입하지 않았다.
4. **접근성 확인 범위**: 대표 조건에서 가로 넘침은 없었고 Tab 이동을 확인했다. 스크린리더·실제 확대·실기기·Safari 검증은 미완료다.

## 후속 순서

교육자 등 2인의 독립 콘텐츠 검토 → 실제 기기·보조기술 확인 → 성인 초보자 사용성 관찰 → 제품 통합 범위 확정 순서로 진행한다. 실제 AI·서버 연결과 제품 배포는 하지 않는다. 합성 시뮬레이션 결과로 이 단계를 대체하지 않는다.
