# Concept Puzzle 독립 프로토타입 검증 결과

버전: 0.1.1
검사 기록일: 2026-10-25 / 환경: 로컬 Chromium

**실제 사용자 검증은 아직 수행하지 않았다.** 아래 결과는 고정 데이터와 모의 상태를 사용하는 독립 프로토타입의 동작 검사다. 교육 효과나 실제 운영 안전성을 검증한 결과가 아니다.

## 완료한 동작 검사
- 첫 5분: 빈 예상·오답·정답, 설명 선택 재시도, 자기 설명 입력 보존, 다른 카드에 적용, 노트 저장·초기화.
- 9문제: C1~C3/R1~R3/U1~U3, 경계값 두 기준, 이름·ID 연결 두 기준, 정답/오답 피드백, 설명 기록 상태.
- 규칙 대안: 3문제 × 점수 기준 4개 × 신규 조건 2개 = 24개 조합의 목표·정원 충족 여부 확인.
- 내장 데이터로 계산한 결과를 명세의 기대 결과와 비교했다. 반례는 고정 사례이며 별도 검토자 2인의 교육적 타당성 검토는 아직이다.
- 질문: 검사 실패·대기·재시도·취소·사람 검토 요청, 발행 대기·수정 요청·제출 철회·초안 보존.
- 답변: 구조화 입력, 실패·대기·재시도·직접 검토, 입력 취소·제출 취소 후 내용과 유형 보존, 사람 승인.
- 요약: 실패·대기·재시도·취소, 원문 연결·사람 확인, 답변 변경·비공개 후 재검토, 회차 종료·재개.
- 신고·항소: 접수·지연·신고 철회, 사람의 비공개/유지 결정, 독립 재심의 변경/유지, 항소 취소 후 원결정 유지.
- 예측이나 설명을 수정하면 이전 결과·기록 완료 표시를 무효화한다.
- 전체 초기화 시 9문제 기록과 참여형 모의 이력을 함께 지운다.
- 데스크톱 1440px 및 모바일 390px에서 주요 화면을 확인했다. 검사한 화면에 가로 넘침은 없었다.
- 브라우저 실행 오류 및 외부 HTTP 요청은 검사에서 발생하지 않았다.
- 기존 제품 작업 복사본은 기준 HEAD b2f7db6d29bf40443a014a30668fa44c958e2ef9 그대로이며 변경 파일이 없다.

## 산출물과 재현 범위

검사한 실행 파일은 기존 제품과 별도로 제공한 `concept-puzzle-prototype/index.html`이다. 이 PR에는 HTML·테스트 스크립트·스크린샷·ZIP을 올리지 않는다. 따라서 이 문서만으로 저장소 CI에서 동일한 브라우저 검사를 재실행할 수는 없다. 실행 파일은 당시 별도 제공한 산출물을 사용해야 한다.

- 독립 HTML SHA-256: `642cd3529084ae74c23d7e1ee96336e0aeea78dc621c5d33e455ea63f1b0f8fa`.
- 로컬 검사 기록: `verify.mjs`(첫 5분·기존 대표 퍼즐), `community-test.mjs`(신고·항소 기본 분기), `v011-test.mjs`(9문제·규칙 24조합·예외 경로), `remaining-paths-test.mjs`(재시도·취소·화면 무효화). 파일명은 기록의 식별용이며 저장소 내 파일 링크가 아니다.
- 관찰한 외부 HTTP 요청·페이지 오류가 없었다는 결과는 해당 로컬 시나리오에 한정된다. 모든 플랫폼의 보안·개인정보 보호를 보증하지 않는다.
- 탭 메모리 기록과 모의 역할 전환은 실제 계정·인증·보존·감사 시스템이 아니다.
